# Fluxo básico de trabalho

> Projeto: CURSO_GITHUB | Módulo 01 | Lição 03

## Fluxo conceptual
1. Criar ou clonar um repositório.
2. Alterar ficheiros.
3. Rever as alterações.
4. Criar um commit.
5. Enviar alterações para o remoto (push), quando aplicável.
6. Confirmar no GitHub que o estado esperado foi publicado.

Na interface web, algumas destas operações são combinadas; no Git local, são normalmente executadas em passos explícitos.

## Exercício guiado
- Criar `NOTAS.md`.
- Escrever três linhas sem informação sensível.
- Registar a alteração.
- Abrir o commit e validar o conteúdo.

## Critérios
- [ ] O ficheiro existe no ramo esperado.
- [ ] O commit tem mensagem descritiva.
- [ ] O conteúdo publicado corresponde ao pretendido.
