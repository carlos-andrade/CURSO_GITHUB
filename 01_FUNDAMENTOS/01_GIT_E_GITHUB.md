# Git e GitHub

> Projeto: CURSO_GITHUB | Módulo 01 | Lição 01

## Conceitos
- **Git:** sistema distribuído de controlo de versões que regista alterações ao longo do tempo.
- **GitHub:** plataforma para alojar repositórios Git e colaborar através de Issues, Pull Requests, revisão, automação e publicação.
- **Repositório:** conjunto de ficheiros e metadados de histórico de um projeto.
- **Commit:** registo identificado de um conjunto de alterações.
- **Branch:** linha de desenvolvimento que permite trabalhar isoladamente.
- **Remote:** referência a um repositório remoto, frequentemente alojado no GitHub.

Git pode funcionar localmente sem GitHub. GitHub acrescenta alojamento, colaboração e serviços em torno do Git.

## Prática
1. Abrir um repositório de treino.
2. Localizar a lista de ficheiros.
3. Abrir o histórico de commits.
4. Abrir um commit e observar a diferença (diff).
