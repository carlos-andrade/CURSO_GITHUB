# Releases e tags

> Projeto: CURSO_GITHUB | Módulo 10 | Lição 01

Uma tag identifica um ponto do histórico, frequentemente uma versão. Uma release reúne uma versão identificada, notas de versão e, quando aplicável, artefactos.

## Prática
1. Rever o histórico de um repositório de treino.
2. Definir uma versão de exemplo.
3. Preparar notas que resumam alterações, correções e limitações.
4. Validar que a release aponta para o commit pretendido.

Referência: https://docs.github.com/en/repositories/releasing-projects-on-github
