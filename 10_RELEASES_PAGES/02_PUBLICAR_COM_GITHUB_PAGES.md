# Publicar com GitHub Pages

> Projeto: CURSO_GITHUB | Módulo 10 | Lição 02

GitHub Pages pode publicar sites estáticos a partir de fontes suportadas e da configuração do repositório.

## Prática
1. Preparar uma página HTML simples e sem dados privados.
2. Consultar as definições de Pages e escolher a fonte suportada.
3. Guardar as alterações e acompanhar o deployment.
4. Abrir o URL publicado e validar conteúdo, ligações e layout.
5. Investigar logs se a publicação falhar.

Referência: https://docs.github.com/en/pages
