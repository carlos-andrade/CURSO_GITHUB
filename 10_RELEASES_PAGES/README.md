## Critérios de conclusão

- [ ] Explicar a diferença entre commit, tag e release.
- [ ] Preparar notas de versão com alterações, correções e limitações.
- [ ] Confirmar que a tag aponta para o commit esperado.
- [ ] Publicar um site estático sem dados privados.
- [ ] Acompanhar o deployment e verificar o URL publicado.
- [ ] Diagnosticar falhas usando a configuração e os logs disponíveis.

## Segurança e qualidade

Não publique segredos, dados pessoais ou conteúdo sem autorização. Confirme as definições de visibilidade e a origem do deployment. Um estado de workflow bem-sucedido não substitui a abertura e verificação do site publicado.
