# Comandos essenciais

> Projeto: CURSO_GITHUB | Módulo 03 | Lição 02

```bash
git status
git diff
git add README.md
git diff --staged
git commit -m "docs: atualiza README"
git log --oneline
```

- `status`: estado da árvore de trabalho e staging.
- `diff`: alterações ainda não preparadas.
- `add`: prepara alterações para o próximo commit.
- `diff --staged`: revê o que será incluído no commit.
- `commit`: cria um registo no histórico.
- `log`: consulta commits anteriores.

Prática: executar cada comando num repositório de treino e anotar o que mudou no estado apresentado.
