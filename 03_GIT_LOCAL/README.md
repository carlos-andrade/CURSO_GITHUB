## Resultado do módulo

O aluno consegue confirmar a instalação do Git, configurar a autoria, inspecionar e registar alterações, sincronizar um remoto e escolher uma recuperação segura para situações comuns.

## Ordem das lições

1. [`01_INSTALACAO_E_CONFIGURACAO.md`](01_INSTALACAO_E_CONFIGURACAO.md) — instalação e identidade de autoria.
2. [`02_COMANDOS_ESSENCIAIS.md`](02_COMANDOS_ESSENCIAIS.md) — status, diff, add, commit e log.
3. [`03_REMOTOS_E_SINCRONIZACAO.md`](03_REMOTOS_E_SINCRONIZACAO.md) — clone, fetch, pull e push.
4. [`04_DESFAZER_COM_SEGURANCA.md`](04_DESFAZER_COM_SEGURANCA.md) — recuperar alterações sem perder trabalho inadvertidamente.

## Pré-requisitos

- Concluir os módulos 00–02.
- Ter Git instalado e acesso a um terminal.
- Ter um repositório de treino sem dados sensíveis.

## Checklist de conclusão

- [ ] `git --version` funciona.
- [ ] A identidade de autoria está configurada conscientemente.
- [ ] Sei inspecionar alterações antes de preparar e criar commits.
- [ ] Sei explicar a diferença entre fetch, pull e push.
- [ ] Consigo verificar se um commit ficou publicado.
- [ ] Sei distinguir alteração não commitada de commit partilhado.
- [ ] Não uso comandos destrutivos sem compreender o efeito.
