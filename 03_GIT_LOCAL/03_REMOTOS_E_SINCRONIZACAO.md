# Remotos e sincronização

> Projeto: CURSO_GITHUB | Módulo 03 | Lição 03

## Conceitos
Um remoto liga o repositório local a outro repositório, por exemplo no GitHub. Os comandos mais comuns incluem:

```bash
git remote -v
git fetch
git pull
git push
```

- `fetch` obtém referências e objetos do remoto sem integrar automaticamente as alterações na branch atual.
- `pull` obtém e integra alterações, conforme a configuração.
- `push` publica commits no remoto.

## Prática
Usar um repositório de treino, observar `git remote -v`, executar fetch e verificar o estado antes de integrar alterações.

Referência: https://git-scm.com/docs
