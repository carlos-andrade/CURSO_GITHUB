# Instalação e configuração do Git

> Projeto: CURSO_GITHUB | Módulo 03 | Lição 01

1. Instalar Git a partir de https://git-scm.com/downloads.
2. Confirmar com `git --version`.
3. Configurar a identidade de autoria segundo as instruções oficiais.
4. Confirmar configuração com `git config --list`, tendo atenção a dados pessoais exibidos.

Exemplos de configuração:
```bash
git config --global user.name "Nome de autoria"
git config --global user.email "email-de-autoria@example.com"
```

Usar valores próprios apenas no terminal local. Não publicar ficheiros de configuração pessoais nem credenciais.

Referência: https://git-scm.com/book/en/v2/Getting-Started-First-Time-Git-Setup
