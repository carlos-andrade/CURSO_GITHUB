# 12 — Projeto final

> Projeto: CURSO_GITHUB | Módulo 12 | Estado: especificação inicial

## Objetivo
Construir um repositório utilizável por terceiros, documentado, com histórico claro, colaboração, validações e governação proporcional ao risco.

## Entregáveis
- README completo e estrutura coerente.
- Issues de planeamento e critérios de aceitação.
- Branch e Pull Request documentados.
- Verificações automáticas e segurança básica.
- Release/publicação quando pertinente.
- Relatório final de validação.

A checklist está em `CRITERIOS_ACEITACAO.md`.
