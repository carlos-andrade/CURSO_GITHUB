# Preparar o ambiente

> Projeto: CURSO_GITHUB | Módulo 00 | Lição 02

## Pela interface web
1. Iniciar sessão em https://github.com/.
2. Confirmar o nome da conta e as opções de segurança.
3. Criar um repositório de treino sem dados sensíveis.
4. Adicionar um README e confirmar que aparece na página principal.

## Para trabalho local (módulo 03)
- Instalar Git a partir de https://git-scm.com/downloads.
- Confirmar a instalação com `git --version`.
- Configurar nome e e-mail de autoria apropriados; compreender que ficam associados aos commits.
- Usar autenticação suportada pelo GitHub; não guardar tokens em ficheiros do projeto.
