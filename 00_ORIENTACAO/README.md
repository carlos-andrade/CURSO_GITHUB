> **Cabeçalho histórico**  
> Projeto: CURSO_GITHUB  
> Repositório oficial: https://github.com/carlos-andrade/CURSO_GITHUB  
> Módulo: 00 — Orientação e preparação  
> Finalidade: preparar o aluno para estudar, executar práticas e registar evidências com segurança.  
> Estado: conteúdo-base publicado; validação integral em curso.

## Resultado do módulo

O aluno consegue orientar-se no curso, criar um repositório de treino, escolher a próxima lição, registar o resultado e pedir ajuda com informação suficiente sem expor credenciais.

## Pré-requisitos

- Navegador atualizado e acesso à Internet.
- Conta GitHub para exercícios de criação e colaboração.
- Computador com Git e terminal apenas a partir do módulo 03.
- Não é necessário saber programar para iniciar.

## Prática obrigatória

1. Criar ou escolher um repositório de treino sem dados confidenciais.
2. Confirmar que existe um README e que é possível consultar o histórico.
3. Iniciar um registo em [`../REGISTOS/PROGRESSO_TEMPLATE.md`](../REGISTOS/PROGRESSO_TEMPLATE.md).
4. Identificar o próximo módulo e os pré-requisitos.

## Critérios de conclusão

- [ ] Explicar a diferença entre ler uma lição, executar uma prática e validar o resultado.
- [ ] Abrir o repositório de treino e localizar o README e o histórico.
- [ ] Registar objetivo, resultado esperado, resultado observado e evidência.
- [ ] Identificar pelo menos três tipos de informação que nunca devem ser publicados como segredos.
- [ ] Saber diagnosticar uma falha sem repetir comandos cegamente.
- [ ] Identificar a próxima lição do percurso.

## Regra de segurança

Todas as práticas iniciais devem usar dados fictícios. Nunca guardar tokens, palavras-passe, cookies, chaves privadas ou dados pessoais desnecessários em Issues, commits, ficheiros ou capturas de ecrã.
