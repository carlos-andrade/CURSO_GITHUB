# EX-003 — Branch e Pull Request

> Projeto: CURSO_GITHUB | Exercício 003 | Nível: intermédio

## Objetivo
Propor uma alteração por Pull Request.

## Passos
1. Criar branch de trabalho.
2. Fazer uma alteração pequena e delimitada.
3. Rever o diff e criar commit.
4. Publicar a branch se trabalhar localmente.
5. Abrir PR com contexto, resumo e validação.
6. Rever antes de integrar.

## Critérios
- [ ] PR com título e descrição objetivos.
- [ ] Diff revisto.
- [ ] Verificações e revisão consideradas.
- [ ] Resultado final confirmado.
