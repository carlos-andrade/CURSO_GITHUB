# EX-007 — Criar um README útil

> **Cabeçalho histórico**  
> Projeto: CURSO_GITHUB  
> Repositório oficial: https://github.com/carlos-andrade/CURSO_GITHUB  
> Tipo: exercício prático de integração  
> Nível: iniciante  
> Estado: pronto para execução pelo aluno; validação externa pendente.

## Objetivo

Criar um README que permita a outra pessoa compreender o propósito de um repositório e executar o primeiro passo.

## Preparação

Usar um repositório de treino. Não usar dados privados nem copiar credenciais para o README.

## Tarefa

Criar ou atualizar `README.md` com:
1. título claro;
2. problema ou objetivo do projeto;
3. descrição curta do conteúdo;
4. instruções de utilização ou próximos passos;
5. estado atual e limitações;
6. forma de reportar problemas, se aplicável.

## Critérios de aceitação

- [ ] O ficheiro aparece na página inicial do repositório.
- [ ] O título e objetivo são compreensíveis sem contexto adicional.
- [ ] As instruções são específicas e não prometem funcionalidades inexistentes.
- [ ] As ligações funcionam.
- [ ] O commit aparece no histórico.
- [ ] Não existem segredos nem dados pessoais desnecessários.

## Evidência

Registar o URL do README e do commit. No relatório, explicar uma decisão editorial e uma melhoria que faria após receber feedback.

## Reflexão

- O que ficou mais claro para uma pessoa externa?
- Que instrução ainda depende de contexto?
- Como verificou as ligações?
