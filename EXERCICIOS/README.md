## Regras de execução

- Usar um repositório de treino, salvo indicação explícita em contrário.
- Ler o objetivo e os critérios antes de começar.
- Registar o resultado esperado e o observado.
- Guardar URL do ficheiro, commit, Issue, Pull Request ou execução relevante.
- Não anexar credenciais, tokens, dados privados ou capturas não anonimizadas.
- Marcar como validado apenas quando todos os critérios forem verificados.
