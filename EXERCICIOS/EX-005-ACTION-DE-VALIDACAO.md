# EX-005 — Action de validação

> Projeto: CURSO_GITHUB | Exercício 005 | Nível: intermédio

## Passos
1. Ler a introdução ao GitHub Actions.
2. Criar um workflow de teste num repositório de treino.
3. Executar o workflow.
4. Inspecionar resumo e logs.
5. Introduzir uma falha segura, observar o diagnóstico, corrigir e repetir.

## Critérios
- [ ] Workflow executado.
- [ ] Resultado e logs inspecionados.
- [ ] Falha e correção documentadas.
- [ ] Nenhum segredo exposto.
