# EX-001 — Primeiro repositório

> Projeto: CURSO_GITHUB | Exercício 001 | Nível: iniciante

## Objetivo
Criar um repositório de treino com README.

## Passos
1. Criar um repositório com nome claro.
2. Escolher conscientemente a visibilidade.
3. Adicionar README com objetivo, conteúdo e estado.
4. Confirmar que o README aparece na página principal.

## Critérios
- [ ] Repositório criado.
- [ ] README compreensível.
- [ ] Visibilidade confirmada.
- [ ] URL registado no relatório de progresso.

Não usar dados privados ou credenciais reais.
