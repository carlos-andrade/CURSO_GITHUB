## Regra permanente de fim de chat

No final de cada chat relacionado com o projeto CURSO_GITHUB:

1. Verificar as alterações efetivamente guardadas no repositório.
2. Atualizar a escala apenas se houver evidência suficiente para alterar a pontuação.
3. Registar a variação e a evidência em ESCALA_DE_CONCLUSAO.md.
4. Apresentar a barra preenchida, a percentagem atual, a variação desde a medição anterior e a próxima prioridade na resposta final.

Se não houver progresso mensurável, mostrar a mesma barra e dizer que a percentagem não mudou. Não declarar validação de exercícios ou módulos sem execução comprovada.
