# Criar e gerir branches

> Projeto: CURSO_GITHUB | Módulo 04 | Lição 01

No terminal:
```bash
git switch -c docs/atualizar-guia
git status
```

Criar nomes curtos e descritivos. Evitar desenvolver alterações independentes diretamente na branch principal quando o projeto exige revisão.

Para regressar a uma branch existente, usar `git switch nome-da-branch`. Antes de mudar de branch, verificar alterações locais para evitar perda ou mistura de trabalho.

Referência: https://docs.github.com/en/get-started/using-git/about-git-branches
