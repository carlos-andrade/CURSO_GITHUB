## Fluxo recomendado
Branch de trabalho → commits pequenos → Pull Request → verificações automáticas → revisão → correções → merge → confirmação na branch de destino.

## Critérios
- [ ] Criar uma branch para uma alteração.
- [ ] Abrir Pull Request com objetivo e testes.
- [ ] Ler comentários de revisão.
- [ ] Confirmar o resultado da integração.

Referência: https://docs.github.com/en/pull-requests
