# Abrir um Pull Request

> Projeto: CURSO_GITHUB | Módulo 04 | Lição 02

Um Pull Request (PR) propõe integrar alterações de uma branch noutra e permite discussão, revisão e verificações automáticas.

## Descrição mínima
- Objetivo e contexto.
- Resumo das alterações.
- Testes executados e resultados.
- Riscos, limitações e passos de validação.
- Ligações a Issues relacionadas, quando aplicável.

## Exercício
Criar uma branch, editar um documento, publicar a branch e abrir um PR. Não fazer merge até rever o diff e confirmar os critérios do exercício.

Referência: https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/about-pull-requests
