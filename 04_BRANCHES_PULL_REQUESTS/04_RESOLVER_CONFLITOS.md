# Resolver conflitos

> Projeto: CURSO_GITHUB | Módulo 04 | Lição 04

Um conflito ocorre quando Git não consegue combinar automaticamente alterações concorrentes.

## Procedimento
1. Ler as secções em conflito e identificar as intenções de cada alteração.
2. Escolher uma solução coerente; não remover conteúdo apenas para eliminar os marcadores.
3. Remover os marcadores de conflito.
4. Rever o ficheiro completo e o diff.
5. Executar testes e validar o resultado.
6. Registar a resolução e continuar o fluxo de integração.

Praticar num repositório descartável. Nunca resolver conflitos em ficheiros críticos sem cópia e validação.

Referência: https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/addressing-merge-conflicts
