## Critérios de conclusão

- [ ] Produzir um comentário de revisão específico e respeitoso.
- [ ] Distinguir bloqueadores, questões e sugestões.
- [ ] Responder a feedback com alterações e evidências.
- [ ] Ler as regras antes de contribuir para um projeto externo.
- [ ] Confirmar que o diff final corresponde ao objetivo.
- [ ] Evitar divulgar segredos ou informação privada.
