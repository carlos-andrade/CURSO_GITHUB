# REST API e autenticação

> Projeto: CURSO_GITHUB | Módulo 11 | Lição 01

A REST API permite consultar e gerir recursos do GitHub por HTTP. Endpoints públicos podem permitir leitura sem autenticação; operações protegidas exigem autenticação e permissões adequadas.

## Prática
1. Consultar a documentação de um endpoint de leitura pública.
2. Identificar método, parâmetros, resposta e códigos de estado.
3. Registar um exemplo de resposta sem dados pessoais.
4. Se testar autenticação, usar credenciais autorizadas e nunca as colocar no código, logs ou commits.

Referência: https://docs.github.com/en/rest
