## Resultado do módulo

O aluno consegue navegar num repositório, editar documentação pela interface web, localizar o commit e avaliar visibilidade e permissões sem alterar configurações reais de forma inadvertida.

## Lições

1. [`01_NAVEGAR_REPOSITORIO.md`](01_NAVEGAR_REPOSITORIO.md) — ficheiros, branches e histórico.
2. [`02_EDITAR_FICHEIROS_E_HISTORICO.md`](02_EDITAR_FICHEIROS_E_HISTORICO.md) — edição, diff e commit.
3. [`03_VISIBILIDADE_E_PERMISSOES.md`](03_VISIBILIDADE_E_PERMISSOES.md) — acesso, visibilidade e riscos.

## Prática integradora

Editar uma frase do README num repositório de treino, rever o diff, criar o commit e guardar os URLs do ficheiro e do commit no relatório.

## Critérios de conclusão

- [ ] Localizo o README, um ficheiro e o histórico.
- [ ] Confirmo a branch antes de editar.
- [ ] Crio uma alteração e verifico o diff.
- [ ] Localizo o commit criado.
- [ ] Distingo visibilidade de permissões.
- [ ] Registo evidência e não exponho informação sensível.
