> Estado: publicado; prática individual pendente.

## Resultado esperado

Conseguir editar um ficheiro de treino, rever o conteúdo, criar um commit e confirmar que o resultado ficou na branch correta.

## Procedimento seguro

1. Abrir o repositório de treino e confirmar a branch.
2. Abrir o ficheiro correto e usar a opção de edição disponível.
3. Fazer uma alteração pequena e intencional.
4. Rever o conteúdo completo, não apenas a linha modificada.
5. Escolher uma mensagem de commit que descreva a alteração.
6. Se a interface oferecer essa opção, criar uma branch e propor Pull Request quando a alteração precisar de revisão.
7. Confirmar a criação do commit.
8. Abrir o ficheiro publicado e o histórico para verificar o resultado.

## O que verificar antes de guardar

- O ficheiro e a branch são os pretendidos.
- O diff não contém alterações inesperadas.
- Não foram incluídos tokens, palavras-passe, dados privados ou ficheiros desnecessários.
- A mensagem de commit descreve a mudança real.

## Exercício autónomo

Alterar uma frase do README de treino para tornar uma instrução mais clara. Guardar com uma mensagem específica e abrir o commit para verificar a diferença.

## Critérios de aceitação

- [ ] O ficheiro correto foi alterado.
- [ ] O diff corresponde à intenção.
- [ ] O commit tem uma mensagem descritiva.
- [ ] A alteração aparece na branch esperada.
- [ ] O histórico permite localizar a mudança.
- [ ] A evidência foi registada sem dados sensíveis.

## Recuperação

Se o conteúdo ficar incorreto, editar novamente e criar um commit corretivo. Não tentar apagar ou reescrever o histórico sem compreender as consequências.
