# Editar ficheiros e consultar histórico

> Projeto: CURSO_GITHUB | Módulo 02 | Lição 02

## Procedimento seguro
1. Abrir o ficheiro correto.
2. Usar a opção de edição disponível.
3. Rever todo o conteúdo alterado.
4. Escolher uma mensagem de commit clara.
5. Se for disponibilizada a opção, preferir criar uma branch e propor Pull Request para alterações que exijam revisão.
6. Confirmar o commit e rever o resultado.

A interface pode variar. Consultar a documentação oficial se os nomes ou opções forem diferentes.

Referência: https://docs.github.com/en/repositories/working-with-files/managing-files
