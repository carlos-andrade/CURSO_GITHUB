# Visibilidade e permissões

> Projeto: CURSO_GITHUB | Módulo 02 | Lição 03

## Conceitos
A visibilidade pública permite que qualquer pessoa veja o conteúdo público; privada limita o acesso aos utilizadores autorizados. As permissões controlam ações como leitura, escrita, manutenção e administração.

## Prática
1. Abrir as definições do repositório de treino.
2. Identificar a visibilidade atual e onde é configurada.
3. Consultar colaboradores/permissões, se disponíveis.
4. Não alterar a visibilidade de um repositório real sem avaliar consequências.

## Critérios
- [ ] Explicar a diferença entre público e privado.
- [ ] Distinguir leitura, escrita e administração.
- [ ] Identificar o risco de publicar dados acidentalmente.
