# Navegar num repositório

> Projeto: CURSO_GITHUB | Módulo 02 | Lição 01

## Elementos a reconhecer
- Separador Code e árvore de ficheiros.
- Branch selecionada.
- Histórico de commits.
- Issues e Pull Requests.
- Actions, Settings e separadores adicionais conforme permissões e funcionalidades ativadas.

## Exercício
Abrir um repositório de treino e encontrar: README, um ficheiro, o histórico e as definições de visibilidade.

## Critérios
Registar os URLs das páginas consultadas e explicar para que serve cada área.
