## Resultado esperado

Conseguir orientar-se num repositório e localizar as páginas necessárias para executar e verificar uma tarefa simples.

## Elementos a reconhecer

- **Code:** árvore de ficheiros e conteúdo da branch selecionada.
- **Branch selector:** indica a branch consultada e permite mudar de branch.
- **README:** descrição e instruções iniciais do projeto.
- **Commits / History:** histórico de alterações, dependendo do ecrã e do caminho utilizado.
- **Issues:** tarefas, perguntas e defeitos registados.
- **Pull requests:** propostas de alterações e respetiva revisão.
- **Actions:** execuções de automatização, quando existem workflows.
- **Settings:** configuração do repositório, visível conforme permissões.

Os separadores e os nomes apresentados podem variar com o contexto, a largura do ecrã, as permissões e as alterações da interface GitHub.

## Prática guiada

1. Abrir o repositório de treino.
2. Confirmar o proprietário e o nome do repositório.
3. Identificar a branch selecionada.
4. Abrir o README e depois outro ficheiro.
5. Localizar o histórico de commits e abrir um commit.
6. Identificar onde seriam consultadas Issues, Pull Requests e Actions, se existirem.
7. Localizar a visibilidade pública/privada sem alterar a configuração.

## Exercício autónomo

Escolher uma tarefa simples — por exemplo, corrigir uma frase do README — e anotar a sequência de páginas que precisa de visitar antes e depois da alteração.

## Critérios de aceitação

- [ ] Confirmo o repositório e a branch corretos.
- [ ] Localizo README, ficheiro e histórico.
- [ ] Sei onde consultar Issues e Pull Requests.
- [ ] Sei onde procurar as execuções das Actions.
- [ ] Registo URLs de evidência e não altero definições sem necessidade.
