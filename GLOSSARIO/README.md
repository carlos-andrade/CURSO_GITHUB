# Glossário Git e GitHub

> Projeto: CURSO_GITHUB | Área: glossário | Estado: versão inicial

- **Action:** componente ou passo de automação no GitHub Actions.
- **Branch:** referência a uma linha de desenvolvimento.
- **CI/CD:** integração contínua e entrega/implementação contínuas.
- **Clone:** cópia local de um repositório remoto.
- **Commit:** registo de alterações no histórico.
- **Diff:** representação das diferenças entre estados.
- **Fork:** cópia de um repositório para outro espaço de conta/organização.
- **Issue:** registo de tarefa, bug, pergunta ou proposta.
- **Merge:** integração de históricos de branches.
- **Pull Request (PR):** proposta de integração com discussão e revisão.
- **Remote:** repositório remoto configurado no Git local.
- **Repository:** conjunto de ficheiros e histórico.
- **Runner:** ambiente que executa jobs do GitHub Actions.
- **Tag:** referência nomeada usada frequentemente para assinalar versões.
- **Workflow:** processo automatizado definido num ficheiro YAML.
- **YAML:** formato de configuração usado em workflows.
