# Markdown essencial

> Projeto: CURSO_GITHUB | Módulo 06 | Lição 01

## Elementos frequentes
```markdown
# Título
## Secção
**negrito** e *itálico*
- item de lista
- [ ] tarefa por concluir
[Texto do link](https://docs.github.com/)
```

Markdown também suporta código, tabelas, imagens e citações. Manter hierarquia de títulos lógica e texto alternativo em imagens.

## Exercício
Criar um documento com títulos, lista, ligação, checklist e bloco de código; confirmar a renderização no GitHub.

Referência: https://docs.github.com/en/get-started/writing-on-github
