# README e estrutura documental

> Projeto: CURSO_GITHUB | Módulo 06 | Lição 02

Um README deve responder rapidamente: o que é o projeto, para quem serve, como começar, como usar, como contribuir e onde obter ajuda.

## Estrutura sugerida
- Objetivo e estado.
- Funcionalidades/âmbito.
- Instalação e utilização.
- Exemplos.
- Testes e validação.
- Contribuição e segurança.
- Licença e referências.

Usar ligações relativas para documentos do mesmo repositório quando apropriado. Rever ligações e manter a documentação alinhada com o comportamento real.
